# 클라우드 컴퓨팅

- 인터넷을 통해 요구가 있을 때 즉시(on-demand) IT 자원을 제공하며 사용한 만큼  비용을 지불하는 서비스
    - **온프레미스(on-premises)**: 사용자 입장에서 공간, 자원 등 모든 것을 자체적으로 구축 및 운영하는 방식

## 클라우드 컴퓨팅 이점

- **민첩성**
    - 광범위한 기술에 쉽게 접근 가능
- **탄력성**
    - 비즈니스 요구가 가변적인 상황에서 자원을 손쉽게 확장, 축소하여 탄력적 운영 가능
- **비용 절감**
    - 사용한 만큼 비용 지불

## 클라우드 컴퓨팅 서비스 유형

- **IaaS (Infrastructure as a Service)**
    - 인프라에 대한  클라우드 서비스 유형
    - 인프라: 서버, 네트워크, 스토리지 등 하드웨어 영역 + 가상화 기능
    - 공급자는 해당 인프라 영역을 관리, 서비스 제공, 사용자가 나머지 영역을 직접 관리
- **PaaS (Platform as a Service)**
    - 플랫폼 형태로 제공되는 클라우드 서비스 유형
    - 클라우드 공급자가 자체적으로 구축한 플랫폼 제공, 사용자는 애플리케이션을 개발 및 관리만
- **SaaS (Software as a Service)**
    - 소프트웨어 영역까지 클라우드 공급자가 관리 및 제공하는 유형
    - 사용자는 별도의 애플리케이션 설치, 운영 없이 클라우드 서비스를 제공받음

## 클라우드 구축 모델

- **퍼블릭 클라우드 구축 모델**
    - 사용자가 클라우드 자원을 소유하지 않음
    - 자체적인 공간에 위치하지 않고 클라우드 공급자가 서비스를 제공하는 환경
    - AWS, GCP, Azure 등
    - 온디멘드 형태, 확장성이 우수, 글로벌 서비스 제공에 유리함
- **프라이빗 클라우드 구축 모델**
    - 사용자 전용 클라우드 환경
    - 자원 소유권은 사용자한테 있고, 온프레미스 환경에 구축되어 서비스를 받는 환경
    - 서비스 주체가 ‘사용자’
    - 서비스 확장성은 퍼블릭보다 떨어짐
- **하이브리드 클라우드 구축 모델**
    - 퍼블릭 클라우드와 프라이빗 클라우드의 단점을 보완하는 모델
    - 클라우드 시스템이 서로 연결된 모델
