# Amazon Route 53

- Amazon Route 53은 주로 **도메인 이름 등록**과 **호스팅 영역 생성**, **레코드 작성** 같은 기능을 제공

## Amazon Route 53 주요 기능

### 도메인 이름 등록

- 도메인 이름을 사용하려면 도메인 이름을 등록하는 절차가 필요함
- 도메인을 등록하려면 전 세계에 위치한 네임 서버에 도메인 이름을 사용한다고 알려야 하는데 이 작업은 개인이 아닌 등록대행소에서 관장함
    - 사용자가 도메인 등록대행소에 도메인 이름 등록을 요청하면 도메인 등록 작업을 대행하는 것
    - Amazon Route 53도 도메인 등록대행소 역할을 수행
- 도메인 영역별 네임 서버를 관리하고 등록을 관장하는 단체
    - **ICANN**: 루트 네임 서버를 관리하고 TLD 네임 서버를 등록하는 역할을 수행하는 비영리 단체
    - **등록소**: 기관이나 기업들이 TLD 네임 서버를 관리하고 권한 있는 네임 서버를 등록하는 역할 수행
- Amazon Route 53 도메인 등록대행소는 도메인 이름의 TLD에 해당하는 등록소로 도메인 등록 작업을 수행

### 호스팅 영역 생성

- 호스팅 영역을 생성하여 네임 서버를 관리할 수 있음
- 호스팅 영역을 생성해야 Amazon Route 53이 등록된 도메인 이름에 대한 권한 있는 네임 서버이자 SLD 네임 서버의 역할을 수행할 수 있음
- 호스팅 영역의 네임 서버들은 고가용성을 위해 다수의 서버로 구성
    
    ⇒ 마치 네임 서버들의 Zone을 구성하는 개념
    

### 레코드 작성

- DNS 레코드를 정의하여 도메인에 대한 요청 처리 방법을 정의할 수 있음
- DNS 레코드는 다양한 형태의 라우팅 정책을 연결하여 도메인 요청에 대한 응답 방식을 정의할 수 있음

## Amazon Route 53의 라우팅 정책

### 단순 라우팅 정책

- 도메인에 대해 특정 대상을 지정하는 방식으로 여러 대상이 있으면 랜덤한 대상을 선택하고 응답
- ex) [ongja.com](http://ongja.com) 도메인의 A 레코드가 10.1.1.1과 10.1.1.2로 단순 라우팅 정책으로 레코드 구성
    
    ⇒ DNS 요청에 대해 둘 중 하나의 IP 주소로 랜덤하게 응답
    

### 가중치 기반 라우팅 정책

- 대상의 가중치를 지정하여 비중에 따라 대상을 선택하고 응답
- 가중치는 0~255 범위에서 설정, 대상별 가중치 값을 합산한 전체 가중치를 대상별 가중치로 나누어 비중을 부여함
- ex) [ongja.com](http://ongja.com) 도메인의 A 레코드가 10.1.1.1과 10.1.1.2로 가중치 기반 라우팅 정책으로 레코드를 구성할 때 10.1.1.1의 가중치가 90, 10.1.1.2의 가중치가 10
    
    ⇒ DNS 요청에 대해 10.1.1.1로 응답하는 비중은 90/100, 10.1.1.2로 응답하는 비중은 10/100
    

### 지연 시간 기반 라우팅 정책

- 다수의 리전에 대상 자원이 있으면 사용자와 인접한 리전을 기준으로 대상 자원의 리전까지 지연 시간을 파악해 낮은 지연 시간의 대상을 선택하고 응답
- ex) [ongja.com](http://ongja.com) 도메인의 A 레코드가 10.1.1.1과 10.1.1.2로 지연 시간 기반 라우팅 정책이라고 할 때 10.1.1.1은 도쿄 리전, 10.1.1.2는 런던 리전
    
    ⇒ 사용자 위치상 인접한 대상의 자원의 리전까지 지연 시간을 파악
    

### 장애 조치 라우팅 정책

- 다수의 대상 자원에 대해 액티브와 패시브로 분류하고 대상 상태를 주기적으로 검사하여 액티브 대상을 선택하고 응답
- 액티브 대상이 통신 불가능할 때는 패시브 대상을 액티브로 승격하여 대상 경로로 라우팅

### 지리 위치 라우팅 정책

- 사용자 PC가 지정하는 DNS 서버의 지리적으로 인접한 리전에 위치한 대상으로 경로를 선택하는 정책

### 지리 근접 라우팅 정책

- 지리 위치 정책과 형태가 동일하나 영향도를 조정하는 바이어스(bias)라는 값을 사용하여 제어하는 정책

### 다중 값 응답 라우팅 정책

- DNS 요청에 대해 다수의 값을 반환할 수 있는 정책
