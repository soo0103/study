# HTTP & SNMP

## HTTP(HyperText Transfer Protocol)

- 인터넷에서 데이터를 주고받을 수 있게 하는 표준 프로토콜
- 웹 서버와 클라이언트 간 데이터를 주고받을 경우 사용
- 클라이언트는 서버에 HTTP 요청(request)을 보내고 서버는 그에 대한 응답(response)를 반환
- 다양한 메소드(method)를 사용하여 요청과 응답을 일반 텍스트 형식으로 주고받음
    - GET
        - 서버에서 리소스를 요청
    - POST
        - 서버로 데이터를 전송
    - PUT
        - 서버에 새로운 데이터를 업로드
    - DELETE
        - 서버에서 데이터를 삭제
- HTTP는 TCP 프로토콜을 사용하여 신뢰성 있게 데이터를 송수신
- 80번 포트를 사용

## SNMP(Simple Network Management Protocol)

- 네트워크 장비들을 모니터링하고 관리하는 프로토콜
- 네트워크 장비들에 에이전트(agent)를 설치, SNMP 관리자와 에이전트 간 메시지를 주고받는 방식으로 동작
- 일반적으로 **MIB(Management Information Base)**라는 데이터베이스를 사용하여 네트워크 장비의 상태 정보를 저장하는데 이를 **OID**라 함
- SNMP 관리자가 해당 ID를 요청할 때마다 에이전트가 그에 맞는 자원 정보를 전달하는 방식
- 네트워크 장비들의 성능 모니터링, 구성 변경, 장애 진단 등 다양한 용도로 사용
    
    ⇒ 네트워크의 안정성과 가용성을 높일 수 있음
    
- UDP 프로토콜을 사용, 161번 포트 사용
- SNMP에서 정의된 기본 OID 정보
    - **1.3.6.1.2.1.1.1.0 - sysDescr**
        - sysDescr 값은 장비 설명이며 장비 제조사에 따라 크기에 차이가 있음
        - 장비 정보를 출력할 때는 부가 정보로 출력
    - **1.3.6.1.2.1.1.2.0 - sysObjectID**
        - sysObjectID 값은 장비의 고유한 ID 값을 반환
        - 해당 값을 사용하여 장비 벤더, 장비 종류를 독자적으로 관리 가능
    - **1.3.6.1.2.1.1.3.0 - sysUpTime**
        - sysUpTime 값은 장비가 부팅되어 현재까지 동작한 milli-second 값
        - 쿼리할 때 업데이트되는 정보
    - **1.3.6.1.2.1.1.5.0 - sysName**
        - sysName은 사용자가 장비에 설정한 장비 이름
        - 설정하지 않으면 Null 값을 출력
        - Null 값 출력 시 해당 장비 이름은 IP 주소 혹은 장비 Alias 이름(별칭)으로 출력
