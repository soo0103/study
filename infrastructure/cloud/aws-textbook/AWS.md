# AWS

- 32개의 **리전**(클라우드 서비스를 위해 자원이 모여 있는 물리적 데이터 센터의 지리적 위치)
- 102개의 **가용 영역**(리전 내 구성되는 하나 이상의 개별 데이터 센터)

## AWS Storage

- 퍼블릭 클라우드에 안정적이고 확장성이 높은 스토리지 서비스들로 구성
- Amazon Simple Storage Service(S3), Amazon Elastic File System(EFS), Amazon Elastic Block Store(EBS)

## AWS Database

- 데이터베이스 목적과 용도에 따라 퍼블릭 클라우드에 다양한 데이터베이스 엔진을 제공하여 완전 관리형 데이터베이스 서비스
- Amazon Relational Database Service(RDS), Amazon Aurora, Amazon DynamoDB

## AWS Security, Identity & Compliance

- 퍼블릭 클라우드 자원과 사용자 자격 증명 및 접근 관리, 데이터‧네트워크‧애플리케이션 보호와 위협 탐지 및 모니터링을 위한 다양한 서비스로 구성
- AWS Identify & Access Management(IAM)
