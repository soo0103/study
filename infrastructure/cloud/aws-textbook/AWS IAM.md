# AWS IAM

## AWS IAM이란

- **AWS IAM(Identity & Access Management)**은 AWS 서비스와 리소스에 안전하게 접근할 수 있도록 관리하는 기능
- IAM을 이용하여 리소스를 사용하도록 **인증**과 **권한**을 통제
- AWS 사용자 그룹을 만들고 관리하거나 권한을 이용하여 AWS 리소스 접근을 허용하거나 거부할 수 있음
- AWS IAM은 대부분의 AWS 서비스와 연결되어 활용할 수 있으며 추가 비용 없이 사용 가능

## AWS IAM 구성 요소 및 동작 방식

### 구성 요소

- AWS IAM은 사용자, 그룹, 역할, 정책으로 구성
- 허가 받은 사용자는 AWS IAM 구성 요소 중 사용자와 그룹으로 볼 수 있음
- 권한은 AWS IAM 구성 요소 중 정책과 역할로 볼 수 있음
- AWS IAM 구성 요소
    - **AWS 계정 루트 사용자**
        - 맨 처음 생성된 AWS 계정이며 해당 계정의 모든 권한을 가짐
    - **IAM 사용자(user)**
        - 별도의 AWS 계정이 아닌 계정 내 사용자이며 각 IAM 사용자는 자체 자격 증명을 보유함
        - IAM 사용자마다 특정 AWS 작업을 수행할 수 있게 권한 통제가 가능
    - **IAM 그룹(group)**
        - IAM 사용자 집합
        - IAM 그룹에 권한을 지정해 다수의 IAM 사용자의 권한을 쉽게 관리할 수 있음
    - **IAM 정책(policy)**
        - 자격 증명이나 리소스와 연결될 때 요청을 허용하거나 거부할 수 있는 권한을 정의하는 AWS 객체
    - **IAM 역할(role)**
        - 특정 권한을 가진 계정에 생성할 수 있는 IAM 자격 증명
        - 역할에는 그와 관련된 암호 또는 접근 키 같은 장기 자격 증명이 없음
        - 역할을 주면 역할 세션을 위한 임시 보안 자격 증명을 제공
        - 역할을 이용하여 일반적으로 AWS 리소스에 접근할 수 없는 사용자, 애플리케이션, 서비스에 접근 권한을 위임 가능
    - **보안 주체(principals)**
        - AWS 계정 루트 사용자, IAM 사용자, IAM 역할을 이용하여 로그인하고 AWS에 요청하는 사람 또는 애플리케이션

### 인증, 인가 동작 방식

- IAM 사용자가 AWS 리소스를 사용할 때 암호나 접근 키 같은 자격 증명을 사용하여 인증 받아야 함
- IAM 사용자 계정에 따른 암호나 접근 키가 올바르다면 적합한 사용자로 간주되어 인증 동작이 마무리
- 인증이 처리되면 IAM 사용자는 적합한 권한이 있는지 확인하는 인가 동작을 진행
- IAM 사용자 이외에 IAM 그룹에 정책을 부여해 그룹별로 편리하게 관리할 수 있음

## AWS IAM 사용자

- **IAM 사용자**는 일반적으로 **루트 사용자**와 **일반 IAM** 사용자로 나뉨
- 루트 사용자는 AWS의 모든 리소스에 접근할 수 있는 전체 권한이 있어 AWS 계정 생성 및 해지와 IAM 사용자 관리 등에 사용
- 직접 AWS 리소스를 사용하도록 권장하지 않음
- 일반적으로 AWS 리소스를 사용할 IAM 사용자를 생성하고 권한을 부여한 후 사용하기를 권장

## AWS IAM 정책

- 사용자를 인가한 후 사용자별로 권한에 대한 확인 절차를 진행
- 사용자별 권한 검사는 AWS IAM 정책을 이용해서 진행
- 사용자에 연결된 IAM 정책으로 사용자별 AWS 서비스와 리소스에 대한 인가(권한)을 얻을 수 있음
- 사용자가 특정 AWS 서비스를 이용하려고 인가 요청 시 IAM은 IAM 정책을 기반으로 AWS 요청을 검사, 평가 후 최종적으로 허용, 차단을 결정
- 정책 동작
    
    ```
    {
    	"Version": "2012-10-17",
    	"Statement": [
    		{
    			"Effect": "Allow or Deny",
    			"principal": "principal",
    			"Action": ["action"],
    			"Resource":["*"],
    			"Condition": {"key":"Value"}
    		}
    	]
    }
    ```
    
    - **Effect**: 명시적 정책에 대한 허용 또는 차단
    - **principal**: 접근을 허용 혹은 차단하고자 하는 대상
    - **Action**: 허용 또는 차단하고자 하는 접근 타입
    - **Resource**: 요청의 목적지가 되는 서비스
    - **Condition**: 명시적 조건이 유효하다고 판단될 수 있는 조건

## AWS IAM 역할

- **IAM 역할**이란 정의된 권한 범위 내 AWS API를 사용할 수 있는 임시 자격 증명을 의미
- 코드에 하드 코딩하지 않고 임시(+Token, 일정 시간 이후 만료됨) 자격 증명을 사용하는데 **Assume**이라 함
- IAM 역할을 사용하면 사용자 권한을 공유하거나 매번 권한을 부여할 필요가 없음
- EC2 Instance Profile, Federations(Cross-Account, SAML2.0, Web Identify Provider)들은 IAM 역할을 활용한 예시
